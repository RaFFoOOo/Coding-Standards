# PostgreSQL — schema, migrations and queries

## 1. Migrations [STRICT]

- **Every schema change is an Alembic revision**, reviewed as SQL (`alembic upgrade --sql`) in the PR
  body. Never edit a revision that has run anywhere; add a new one.
- **A revision is forward-safe**: add a column nullable or with a default, backfill, then constrain
  in a later revision. A destructive change (drop, rename, type narrowing) names the data it moves.
- **The models and the migrations agree**: `alembic check` in CI fails a model change with no revision.
- **Reference data (vocabularies) is seeded by an idempotent revision or script**: running it twice
  changes nothing.

## 2. Types

- **A timestamp is `timestamptz`, written in UTC**; a calendar day is `date` (`AGENTS.md §3`
  *The wire is UTC*).
- **Identifiers are `uuid`** generated by the database (`gen_random_uuid()`), plus a human code where
  the domain has one (a sample code), unique per owning scope.
- **A measured series is an array** (`double precision[]`) beside its unit and axis metadata; the raw
  file stays in object storage, addressed by its content hash.
- **A typed property with a unit is a row, not a column** when the set of properties grows with the
  domain (`name`, `value`, `unit`, `uncertainty`).
- **Money, if any, is `numeric`**, never a float.

## 3. Queries

- **Every query is parameterised**; no string-built SQL, not even for an identifier (use the driver's
  identifier quoting).
- **One query where a join does**: never a loop of queries over a first query's result.
- **Every foreign key is declared and indexed**; a delete rule (`RESTRICT` / `CASCADE`) is chosen,
  never left to the default by accident.
- **A multi-owner table carries its owner's id from the first revision** and every read filters by it,
  so row-level security can be added without a destructive migration.

## 4. Operations

- **Backups are proven by a restore**, not by their existence.
- **The application's role owns no schema**: migrations run as the owner, the app as a role with DML
  only.
